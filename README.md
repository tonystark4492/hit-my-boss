# HIT MY BOSS – Phase 1 (playable prototype)

An office stress-relief physics game. Built with **Phaser 3.90 + Matter.js**, bundled with **Vite**.
Everything (art, sound effects, music) is generated by original code: no downloads, no API keys, and it works offline.

### Honest notes on what is *not* final yet
- **Artwork:** the boss and room are painted with canvas code (shaded 2D). They look clean and stylized, but they are **not** the realistic 3D-rendered look from your reference images. That level of realism needs real image files made in an art tool. The code is ready for them: each body part is its own texture (see section 6), so new art can be dropped in without changing the physics.
- **Voice:** the grunts, gasps and growls are synthesized "cartoon voice" sounds, not recorded voice acting.
- **Not in Phase 1 (by design):** corporate dialogue bubbles (Phase 2), the 10 office objects and the item toolbar (Phase 3), rage meter, combos, coins and the shop (Phase 5), and the Android APK (Phase 7). None of these have fake buttons on screen yet.
- **Testing:** tested in desktop Chrome with mouse and simulated touch (punches, grab/throw, tap, swipe, pause, settings, reset, 200-hit stress test, phone-sized screens). It has **not** been tested on a real Android phone yet. Do that next (see step 4 below).

## 2. What you need (Windows)

1. **Node.js (LTS version)**: https://nodejs.org. You probably already have it. To check, open *Command Prompt* and type `node -v`.
2. **VS Code** (recommended).
3. **Google Chrome** for testing.

---

## 3. Run the game on your PC

1. Unzip `hit-my-boss.zip` somewhere simple, for example `C:\Games\hit-my-boss`.
2. Open VS Code → **File → Open Folder…** → choose the `hit-my-boss` folder.
3. Open a terminal: **Terminal → New Terminal**.
4. Install the libraries (only needed the first time):
   ```
   npm install
   ```
5. Start the game:
   ```
   npm run dev
   ```
6. Open the address it shows (usually **http://localhost:5173**) in Chrome.
7. Click **TAP TO START**. Audio only starts after this first tap, because browsers and Android require it.

To stop the game server, click in the terminal and press **Ctrl + C**.

## 4. Test it on your Android phone (before we make the APK)

1. Your PC and phone must be on the **same Wi-Fi**.
2. Run `npm run dev`. The terminal shows a **Network** address like `http://192.168.1.23:5173`.
3. Open that address in Chrome on your phone and turn the phone sideways.
4. If it doesn't load, Windows Firewall may ask to allow Node.js. Click **Allow** (private networks).

## 5. Make the final web build

```
npm run build
```
This creates a `dist` folder containing the finished, offline game. Capacitor will package this folder into the Android app in Phase 7.

## 6. Project structure (what each file does)

```
hit-my-boss/
├─ index.html               page shell
├─ package.json             libraries + commands (npm run dev / build)
├─ vite.config.js           build settings (relative paths for Android)
└─ src/
   ├─ main.js               starts Phaser, physics settings, blocks zoom/scroll
   ├─ config.js             ALL tunable numbers (gravity, punch cooldown, impact thresholds…)
   ├─ styles.css            UI look (charcoal / orange / purple)
   ├─ core/
   │  ├─ Storage.js         saves settings in localStorage
   │  └─ events.js          event bus that connects game ↔ UI ↔ audio
   ├─ art/
   │  ├─ draw.js            drawing helpers
   │  ├─ RoomArt.js         meeting room, sky, skyline, plants
   │  ├─ BossArt.js         boss body parts, 8 faces, bruise/mark drawing
   │  └─ FxArt.js           fist, comic words, sparks, stars, chair, shadows
   ├─ audio/
   │  ├─ AudioManager.js    volume, mute, pause, variations, voice limiting
   │  ├─ SfxLibrary.js      every sound effect recipe
   │  └─ MusicGenerator.js  the funk loop (chords, bass line, drums, melody)
   ├─ entities/
   │  ├─ bossDefs.js        body part sizes, joints, joint limits, sitting pose
   │  ├─ Boss.js            ragdoll, muscles, damage, expressions, safety resets
   │  └─ Chair.js           rolling office chair
   ├─ systems/
   │  ├─ InputController.js tap / drag / throw / swipe
   │  ├─ PunchController.js punch button + fist animation
   │  ├─ Reactions.js       hit → sound + effects, collision damage
   │  └─ Effects.js         pooled particles, flashes, comic words, dizzy stars
   ├─ scenes/
   │  ├─ BootScene.js       creates all textures at start
   │  └─ GameScene.js       builds the room, colliders, fixed 60 Hz physics loop
   └─ ui/
      ├─ Hud.js             buttons, pause menu, settings, start screen
      └─ icons.js           SVG icons
```

### Useful tweaks
- Punch speed: `HIT.punchCooldownMs` in `src/config.js`
- Heavier or lighter gravity: `PHYSICS.gravityY` in `src/config.js`
- How easily he gets hurt by falling: `HIT.impactSoft` / `HIT.impactHard`
- Use **your own music** (you make music, so this is the place to start): put an mp3 in `public/audio/` (create the folder), then set
  `CUSTOM_MUSIC_FILE = 'audio/music_game.mp3'` in `src/config.js`. It loops automatically and stays offline.

### Swapping in real artwork later
Body part texture keys and sizes (in pixels, part centred in the image) are listed in `src/entities/bossDefs.js` (`tw` × `th`), for example the head is 100×112 and the torso 100×150. Faces are separate transparent images, the same size as the head. When final art exists, it can replace the drawing functions in `BossArt.js` one part at a time.
